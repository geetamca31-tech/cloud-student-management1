# Cloud-Based Student Management System

## 1. Project Overview

The Cloud-Based Student Management System is a web application developed using Python Flask. It helps manage student information digitally, allowing users to add, view, and delete student records.

The project demonstrates cloud application development, database connectivity, and web application deployment.

## 2. Objectives

- Develop a student management web application.
- Perform CRUD operations on student records.
- Connect the application to a database.
- Understand cloud computing services.
- Deploy a web application on a cloud platform.
- Learn environment variables, application security, and monitoring.

## 3. Technologies Used

## 6. Installation and Setup

### Step 1: Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/cloud-student-management.git
```

### Step 2: Open the Project Folder

```bash
cd cloud-student-management
```

### Step 3: Create Virtual Environment

```bash
python -m venv venv
```

### Step 4: Activate Virtual Environment

For Windows PowerShell:

```powershell
.\venv\Scripts\Activate.ps1
```

### Step 5: Install Dependencies

```bash
python -m pip install -r requirements.txt
```

### Step 6: Run the Application

```bash
python app.py
```

### Step 7: Open in Browser

```text
http://127.0.0.1:5000
```

## 7. Application Modules

1. Dashboard Module – Displays student records.
2. Add Student Module – Adds new student information.
3. View Records Module – Displays saved student details.
4. Delete Module – Deletes selected student records.
5. Database Module – Stores student information.
